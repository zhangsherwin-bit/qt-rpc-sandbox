# Programme III — new StablePair directional fee-decay mechanism

**Distinct economic thesis:** Uniswap Labs' new September-2026 v4 StablePair Hook creates block-dependent and direction-dependent transaction fee schedules on Ethereum (USDC/USDT, USDC/USDG). An arbitrageur might optimise *when* the price-correction fee decays enough to make a fully funded same-block cash loop possible against an independent AMM. This is economically distinct from the old direct fixed-fee/Curve V3 dust 3Crv route, liquidation, ERC4626 claims, and keeper service rewards. It is not itself proof of novel exploitable alpha; Uniswap intentionally captures much of the corrective spread for LPs.

### Frozen, independent, public empirical design
- Two officially deployed Ethereum pool keys. Recompute canonical IDs with keccak(abi.encode(PoolKey)) and insist on matching published known IDs *before* any authenticated requests. Dynamic fee flag 0x800000, tickSpacing1, permanent hook 0x0000113dCf4ADd69999Fad8F20F2b63F979bfcC0.
- One canonical latest-5 anchor. Frozen offsets [0,1,2,3,1000,7000,30000,90000] sampled independently of profit. Collect both directional getFee rates for both pools, keeping successive blocks for the time-decay question. No state overrides.
- For USDC/USDT only: at offsets [0,7000,30000,90000] quote finite 100/1000/10000 USDC USDC -> USDT through official v4 quoter -> USDC at Curve 3pool. Also test the reverse acquisition order and a Curve-only roundtrip control. All token inputs/outputs are 6-decimal native USDC/USDT at the **same historical block**, so no fair-value-par shortcut. The quoter includes pool-level dynamic LP fees and price impact; external protocol or gas costs remain unmeasured.
- Distinguish incomplete ABI, missing archive data, insufficient liquidity, negative gross cycles, positive gross cycles, and actual cash execution. A single positive gross quote is not own atomic EVM profit, competitive capturability or repeatable income.
- All original JSON-RPC request/response bytes and SHA retained under stablepair_evidence; user-authorised one-off PR-open empirical test, never automatic updates, no signing or broadcasts, max 230 conservative RU, 1500RU reserve and 55% documented minute limit target.
- Source contracts/documentation: https://developers.uniswap.org/docs/protocols/uniswap-labs-hooks/stable-pair/deployments and https://developers.uniswap.org/docs/protocols/uniswap-labs-hooks/stable-pair/guides/swap and https://github.com/Uniswap/v4-periphery/blob/main/src/interfaces/IV4Quoter.sol

**Success gate:** a genuine finite same-block positive *terminal USDC* quote, reproducible across distinct blocks, then separately prove sequential atomic quote/fork settlement, gas, builder cost, failed inclusion rates, and earliest observable independent execution. Anything less remains Stage1, while baseline Stage2 liquidation shadow-replay continues separately.
